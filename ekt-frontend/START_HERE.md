# С чего начать

Это новая версия **той же папки `ekt-frontend`**.

1. Сохраните текущую рабочую версию в своей ветке GitHub.
2. Замените **только свою прежнюю папку `ekt-frontend`** файлами из архива.
   Если участники уже редактировали эту папку, сначала сравните изменения.
   Файлы других участников и корень репозитория не заменяйте.
3. В терминале Codespaces: `cd ekt-frontend`, затем `npm start`.
   Если вы уже в этой папке, выполняйте только `npm start`.
4. Откройте приватный порт 3000. Начните с «Проверить список».

Второму участнику передайте `API.md`. Реальные товары, AI и корзину ekt.kz
ему ещё нужно подключить. В текущем архиве всё работает на явно обозначенных
учебных данных. Сам архив в GitHub автоматически не загружен.

Проверить код: `npm run check` и `npm test`.
Для запуска не нужен Python и не нужно покупать доступ к какому-либо AI.
При реальном подключении AI доступ команды понадобится отдельно.
