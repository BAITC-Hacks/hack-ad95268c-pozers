# EKT AI Assistant — локальное демо

Откройте `index.html` двойным щелчком в современном браузере. Сборка, установка пакетов, ключи и подключение к интернету не нужны. Используются обычные скрипты, поэтому страница работает и через `file://`.

При необходимости можно запустить локальный сервер из корня проекта:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory frontend
```

Затем открыть http://127.0.0.1:4173/. Остановка сервера — Ctrl+C.

## Что реализовано

- Чат с приветствием, отправкой по кнопке и Enter. Shift+Enter добавляет новую строку. Пустые сообщения и пробелы не отправляются.
- Три явно обозначенных тестовых товара. Цены в тенге, артикулы, характеристики, остатки и условные SVG-иллюстрации.
- Перед добавлением открывается окно с товаром, количеством и суммой. Отмена, крестик и Escape закрывают его без изменения корзины.
- Корзина считает количество и стоимость. Уже добавленные товары учитываются в доступном остатке. Каждое подтверждение можно применить только один раз. Доступно удаление позиции.
- Корзина существует в памяти страницы и очищается при обновлении. Число на значке — сумма количеств всех позиций (включая метры кабеля).
- Адаптивная компоновка, подписи полей, клавиатурный фокус и сообщения для экранного диктора.

Все товары, цены, остатки и ответы вымышлены. ИИ, API и оформление заказа отсутствуют. `certificateUrl` в тестовых товарах равен `null`, поэтому ссылок на сертификаты нет.

## Куда подключать сервер позже

| Файл | Назначение |
| --- | --- |
| `demo-data.js` | Каталог: `id`, `name`, `sku`, `price`, `stock`, `unit`, `kind`, `features`, `certificateUrl`. |
| `assistant-service.js` | `EktDemo.getReply(message)` возвращает `Promise<{ text, productIds }>`. Эту функцию можно заменить адаптером сервера. |
| `cart.js` | Независимая от DOM логика временной демо-корзины и подтверждений. |
| `app.js` | Отображение и обработчики интерфейса. Текст данных вставляется через `textContent`. |
| `styles.css` | Оформление и адаптивность. |
| `index.html` | Каркас страницы и встроенные SVG-иллюстрации. |

`productIds` в ответе должны соответствовать `id` в каталоге. Ссылка «Сертификат» появляется только при явном `certificateUrl` с `http://` или `https://`. Вымышленные ссылки добавлять не нужно. `kind` выбирает одну из трёх локальных иллюстраций: `breaker`, `cable`, `socket`.

Для реального заказа в будущем понадобятся отдельное серверное состояние корзины и серверная проверка цены и остатка. Текущие проверки относятся исключительно к демо.

## Проверки

`tests/run-tests.cjs` содержит 8 проверок логики без сторонних пакетов: отмена, однократное подтверждение, остаток с учётом корзины, недопустимые количества, устаревшие подтверждения, суммы и удаление, отсутствие товара, тестовые ответы и пустые запросы.

При наличии Node.js:

```sh
node frontend/tests/run-tests.cjs
```

Эти проверки выполнены во встроенной среде JavaScript рабочего инструмента, без установки Node.js в проект. Все 8 прошли. Также проверен синтаксис четырёх основных JS-файлов.

Браузерный прогон и визуальная проверка не выполнены: встроенный браузер заблокировал доступ к локальной странице, поскольку не смог проверить административную политику доступа. Проверки логики не подтверждают работу DOM-событий, Enter и внешний вид в реальном браузере.

Для ручной проверки: отправьте сообщение кнопкой и Enter; попробуйте пробелы; откройте добавление и отмените; добавьте 3 выключателя; повторно откройте добавление и попробуйте 6 при доступных 5; введите 0 и 1,5; затем добавьте оставшиеся 5. Ожидается 8 выключателей на 19 600 ₸ и недоступная кнопка добавления этого товара. Проверьте двойной клик по «Подтвердить», Escape и ширины окна 390 и 1280 пикселей.
